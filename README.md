# Aura Chat

Quero que você crie somente a parte do front-end. O máximo parecido com o WhatsApp, mas o meu é personalizado, diferenciado. O meu foco aqui muito grande é a, é a-- muito, é a boa prática de UX/UI design, é a experiência com, pro usuário, que tem que ser muito fácil e um belo visual. Euuu, minha plataforma ela usa Next ou React e Tailwind. Cria somente a parte do front, somente o visual. Pode, pode criar de uma forma que fica encantador, que o usuário vê e fala: "Uau, ficou muito bonito, melhor do que o WhatsApp."
